Claude Code skills

Seven

Claude Code reads a skill before it starts working and follows it like a house rule. These are the seven I keep loaded.

  • SK·01Maverick’s Monkey Werx Three plugins and a browser console for marketing a product with no budget — guerrilla marketing for the Proof Economy. SCOUT finds what’s true, RAID takes ground money can’t buy, FORTRESS won’t publish a claim with no source. Find it, take it, hold it. Public Maverick’s Monkey Werx →
  • SK·02KiSYSTEM Keeps what the AI builds simple on purpose — size budgets, one job per file, and a map so it stops rewriting things that already exist. Used to build this page. Public github.com/…/KiSYSTEM →
  • SK·03Peitho A reader keeps reading because you gave them something to do. Built from the rhetoric that survived two thousand years and the studies that contradict most hook advice, starting with the one where spoiling the ending made readers enjoy it more. Public github.com/…/peitho →
  • SK·04Janus Two things about a product that contradict each other are usually the position it was missing. Every other thinking framework dissolves a contradiction; this one refuses to, and takes what falls out. Public github.com/…/janus →
  • SK·05Wheel to Talk Claude Code’s dictation only binds to keyboard keys. This puts it on the middle mouse button — hold, speak, release. Public github.com/…/wheel-to-talk →
  • SK·06Metaphrasis An AI has no ears, so ask it to pick music and it guesses in confident prose. This measures instead — tempo, key, loudness, where a track can be cut, and whether the music is drowning the narration. It will not tell you how anything sounds. Public github.com/…/metaphrasis →
  • SK·07Paraphrasis Say the same thing to a different reader without the claim quietly growing. Nobody decides to overstate it; rewriting does that on its own. Names nine ways a claim drifts and returns a ledger of what survived. Public github.com/…/paraphrasis →
